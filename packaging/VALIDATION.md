# 发布前验证与恢复清单

当前本地功能实现和测试通过不等于真实 Windows 桌面验收通过。
远端 CI 应对应当前待发布提交，不能使用旧基线的成功记录替代。
以下人工项目均需在隔离 Win10 1809+ / Win11 x64 环境记录版本、场景和结果。

## 自动化验证

- 设置 `GGZIP_7Z` 为 `prepare-engine.ps1` 返回的固定引擎路径，运行当前核心/GUI CTest。
- `diagnostics` 审计核心/CLI/预览的原文键覆盖，验证中文/英文消息、稳定错误码/退出码、
  密码与 `--` 字面量参数、文件名/恢复路径和第三方输出不被翻译修改。
  GUI 回归同时验证后台详情语言、标准控件翻译及无效语言保持已有翻译。
- `resource_benchmark_smoke` / `image_resource_benchmark` 执行有预算的真实处理与异常场景；
  `test-performance.ps1` 可生成更大规模 JSON 报告，详细边界见 `PERFORMANCE.md`。
  不通过整机内存耗尽或填满系统卷来运行这些用例，跳过与检查点大小不能当作完整压力验收。
- `cross_volume` 在有两个可用卷时验证复制、覆盖、冲突回滚、校验后变化、占用与取消。
  单卷环境会明确跳过，不能把跳过当作跨卷成功。
- `archive_volumes` 验证数值分卷、RAR 卷名识别、真实多盘 ZIP 的读取/测试/解压/预览、
  多卷来源标记与 CLI 批量去重。真实 RAR 分卷仍需补充合法测试样本。
- `modern_commands` 直接加载 DLL 验证命令可见性，不注册 COM；
  经典 Shell 宿主、安装/升级/卸载测试只在一次性环境运行。
- `test-filesystems.ps1` 仅允许在 GitHub Actions 一次性 Windows runner 运行。
  它在 runner 临时目录创建新的 256 MiB VHD，通过磁盘映像绑定核对新虚拟磁盘，
  分别验证 FAT32/exFAT 的创建、解压、编辑、选中范围、MOTW 拒绝和真实磁盘满。
  不允许绕过环境守卫，也不接受已有磁盘、分区或外部磁盘映像作为输入。

## 文件系统与权限

- [ ] NTFS 私有目录、共享父目录、跨卷目标均验收创建/解压/编辑与失败回滚。
- [ ] FAT32/exFAT 非来源标记内容可正常创建/解压/编辑；完整明文暂存仍位于私有 ACL 卷。
- [ ] FAT32/exFAT 选中解压不会在目标卷出现未选中的解码内容。
- [ ] 带 MOTW 的卷组不向无 ADS 目标发布；错误提示说明原因，不建议删除安全标记。
- [ ] NTFS 新结果保留私有 ACL；若需要共享，由用户明确配置结果权限。
- [ ] 目标卷空间不足、源暂存卷空间不足、目标被占用及权限不足时旧文件内容不变。
- [ ] 取消大文件复制/校验后及时停止；旧文件不被覆盖，只清理自己创建的不完整数据。
- [ ] 持续目录/ACL 变化与真实跨用户压力下不向重解析目标发布，不清理其他用户数据。

无 ACL 文件系统不能提供最终文件或断电遗留临时文件的用户权限隔离。
普通软件事务也不等于断电安全；断电/进程强制结束应单独测试，不能由异常处理回归代替。

## 压力与恢复

- [ ] 海量小文件、超大单文件、固实包、十万条目列表：记录文件数、总大小、耗时和资源峰值。
- [ ] 超大/畸形图片：记录辅助进程峰值内存，验证超时、像素上限和取消。
- [ ] 磁盘满、低内存、错误密码、损坏包、缺首/中/尾卷均不损坏旧数据。
- [ ] 在受控提交阶段终止进程，检查目标、暂存目录、原文件备份和可操作的恢复提示。

若程序报告恢复目录：

1. 停止对原目标的写入，保存错误提示和恢复目录路径，不直接删除目录。
2. 核对 `commit.txt` 中的 `OLD` / `NEW` 路径及对应 `rollback-*` 备份，
   不在映射不明确时猜测哪个 `.old` 文件属于哪个原目标。
3. 先将备份复制到新的私有目录，按记录恢复原文件名；分卷必须整组恢复。
4. 核对文件内容，压缩包再做完整性测试，确认正确后才决定是否覆盖原目标。
5. 恢复确认前保留备份。当前没有自动断电恢复承诺或无确认的恢复命令。

## 真实桌面验收

- [ ] 安装、升级、卸载和便携启动；中文/空格路径，无另装 7-Zip 或 Qt 的依赖。
- [ ] 经典右键、多选卷组、双击关联、已有默认应用和 `UserChoice` 保护。
- [ ] 多选解压、完整性测试、错误密码重试、密码库明确保存、关闭时取消。
- [ ] 栅格/文本预览、系统打开默认取消、真实 Windows 下载来源安全警告。
- [ ] 批量去重、失败继续/停止、单项/整队取消、ZIP/7z 编辑与分卷只读。
- [ ] 中文/英文文案、布局、截断、原生控件与中文/emoji 文件名。
- [ ] RAR `.partN.rar` / `.r00`、ZIP `.zNN`、数值卷的真实完整/缺卷/加密场景。

Win11 新式菜单必须在可信签名后验证真实 Explorer 可见性、Inno 可选任务、
经典入口去重、注册失败回滚和升级/卸载清理。COM 宿主通过不是生产部署验收。
不在用户机器导入测试证书、不替换默认应用，也不自动安装程序进行这些测试。

## 发布门槛

- [ ] 当前提交的 CI 与以上必要验收通过。
- [ ] 核对版本号、依赖、原始许可、匹配源码、资产和 SHA256。
- [ ] 可信签名方案及干净机器验证完成；未签名包仅作为测试预发布。
- [ ] 用户确认提交/推送和正式版本标签后，再执行对应操作。
